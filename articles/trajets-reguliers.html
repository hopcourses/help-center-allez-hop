Renseigner ses trajets réguliers

Indiquez vos déplacements habituels pour recevoir des notifications ciblées sur les courses disponibles.

À quoi servent les trajets réguliers ?

Les trajets réguliers permettent d'indiquer les déplacements que vous effectuez habituellement et que vous connaissez à l'avance.

En les renseignant dans votre profil, vous pouvez recevoir des notifications ciblées lorsqu'une course devient disponible sur un trajet correspondant.

L'objectif : pouvoir profiter d'une course qui s'intègre naturellement à un déplacement que vous aviez déjà prévu.

Où renseigner ses trajets ?

Depuis votre profil, rendez-vous dans :

Profil → Trajet(s) régulier(s)

Vous pouvez enregistrer jusqu'à 5 trajets réguliers.

Créer un trajet régulier

Pour créer un trajet, renseignez :

1
Code postal de départ

Indiquez le code postal correspondant à la ville de départ.

2
Code postal d'arrivée

Indiquez le code postal correspondant à la ville d'arrivée.

Les deux informations sont obligatoires : un trajet régulier doit comporter un code postal de départ et un code postal d'arrivée.

Jusqu'à 5 trajets réguliers

Vous pouvez enregistrer jusqu'à 5 trajets réguliers simultanément.

Vous pouvez ainsi renseigner plusieurs déplacements habituels si vous effectuez régulièrement différents trajets.

Modifier ou supprimer un trajet

Vos trajets réguliers peuvent être modifiés ou supprimés.

Vous pouvez donc les adapter lorsque vos habitudes de déplacement évoluent.

🔄 Vos trajets changent ?

Pensez à mettre vos trajets réguliers à jour afin que les notifications reçues restent pertinentes.

Comment fonctionnent les notifications ciblées ?

Les trajets réguliers servent à recevoir des notifications ciblées.

Lorsqu'une course devient disponible, une notification peut vous être envoyée si la course correspond à l'une des villes renseignées dans vos trajets réguliers.

📦 Course disponible au départ

Vous pouvez être notifié lorsqu'une course est disponible au départ de l'une des villes renseignées.

📍 Course disponible à l'arrivée

Vous pouvez également être notifié lorsqu'une course est disponible à l'arrivée de l'une des villes renseignées.

Et si je n'ai aucun trajet régulier ?

Ce n'est pas bloquant.

Vous pouvez toujours consulter les courses disponibles directement depuis la page d'accueil de l'App web et utiliser les filtres pour rechercher les courses correspondant à vos déplacements.

Bon réflexe : consultez régulièrement l'App web et restez à l'affût des nouvelles courses disponibles.

Gardez vos trajets à jour

Vos trajets réguliers peuvent être modifiés ou supprimés à tout moment.

Pensez à les actualiser lorsque vos habitudes de déplacement changent afin de conserver des notifications ciblées pertinentes.
