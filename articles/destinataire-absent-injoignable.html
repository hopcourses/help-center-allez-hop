Que faire si le destinataire est absent ou injoignable ?

Les étapes à suivre lorsqu'il est impossible de remettre directement la commande au destinataire.

Le destinataire est absent ou injoignable

Si vous arrivez au lieu de livraison et que le destinataire est absent ou impossible à joindre, ne quittez pas immédiatement les lieux.

Commencez par essayer de contacter le destinataire afin de savoir s'il est simplement retardé ou si une solution peut être trouvée pour remettre la commande.

📞 Premier réflexe : essayez de joindre le destinataire et vérifiez les possibilités de remise de la commande.

Essayez de contacter le destinataire

1
Contactez le destinataire

Utilisez les coordonnées disponibles dans la course afin de tenter de le joindre.

2
Vérifiez les possibilités de remise

Lorsque cela est possible, recherchez avec le destinataire une solution adaptée à la situation.

3
Signalez la situation

Si la livraison ne peut pas être réalisée normalement, informez le support Allez HOP!.

Le destinataire peut-il être remplacé par un voisin ?

Dans certaines situations, une remise à un voisin peut permettre de finaliser la livraison lorsque le destinataire est absent.

Cette solution doit toutefois rester compatible avec les instructions de la course et avec les conditions de remise de la commande.

🏠 Remise à un voisin

Une remise à un voisin peut être envisagée lorsque le destinataire est absent et que cette solution permet une remise sécurisée de la commande.

Et si le destinataire ne peut pas fournir le code confidentiel ?

La livraison peut, dans certains cas, être validée sans code.

Cela peut notamment concerner les situations dans lesquelles le code ne peut pas être récupéré, par exemple lors d'une livraison de fleurs, d'une remise à un voisin ou en cas d'absence du destinataire.

🔐 Pas de code ? La validation sans code reste possible dans les situations prévues.

La validation sans code entraîne-t-elle un problème de paiement ?

Non. La livraison peut être validée sans code lorsque la situation le justifie.

En revanche, lorsque le code n'a pas été entré, une vérification est nécessaire avant de créditer la cagnotte du cotransporteur.

⚠️ À savoir : lorsqu'une livraison est validée sans code, le crédit de la cagnotte peut être légèrement décalé le temps d'effectuer les vérifications nécessaires.

Faut-il quitter les lieux ?

Lorsque la situation peut encore être résolue, restez disponible et suivez les instructions communiquées.

En cas de force majeure ou de situation rendant votre présence impossible ou dangereuse, mettez-vous en sécurité et quittez les lieux si nécessaire.

Contactez ensuite le support dès que la situation le permet.

Et si aucune solution n'est possible ?

Si le destinataire reste injoignable et qu'aucune solution de remise ne peut être mise en place, contactez le support Allez HOP!.

Le support vous indiquera la conduite à tenir pour la suite de la course.

Que faire avec la commande ?

Ne décidez pas seul du devenir de la commande lorsque la livraison ne peut pas être réalisée.

Attendez les instructions du support lorsque la situation nécessite une décision sur la suite à donner.

📦 La commande reste sous votre responsabilité

Manipulez-la avec soin et conservez-la dans les conditions adaptées en attendant les instructions nécessaires.

À retenir

📞 1. Essayez de joindre le destinataire

Utilisez les coordonnées disponibles afin de tenter la remise.

🏠 2. Une remise alternative peut être possible

Une remise à un voisin peut être envisagée lorsque les conditions le permettent.

🔐 3. Le code n'est pas toujours indispensable

Dans certains cas, la livraison peut être validée sans code.

⏳ 4. La cagnotte peut être créditée plus tard

Une validation sans code nécessite une vérification avant le crédit de la cagnotte.

📞 5. Contactez le support

Lorsque aucune solution de remise n'est possible, prévenez le support et suivez ses instructions.

🛡️ 6. Sécurité avant tout

En cas de danger ou de force majeure, mettez-vous en sécurité avant toute autre démarche.
