Que faire si le code-barres ou la référence ne fonctionne pas ?

Les bons réflexes lorsque le code-barres ou la référence pose problème lors du retrait d'une commande.

Présentez-vous à l'accueil du point de retrait

Si vous rencontrez un problème avec le code-barres ou la référence de votre commande, présentez-vous directement à l'accueil du point de retrait.

L'équipe sur place pourra vous indiquer la marche à suivre pour récupérer votre commande.

À savoir : selon le point de retrait, le code-barres, la référence ou le bon de commande peut être utilisé pour permettre le retrait.

Le code-barres ne fonctionne pas

Si le scan du code-barres ne fonctionne pas, présentez-vous à l'accueil du point de retrait afin que l'équipe sur place puisse vous aider.

Si le point de retrait le demande, vous pouvez également présenter le bon de commande.

La référence fonctionne

Si le code-barres ne peut pas être utilisé mais que la référence de la commande est acceptée par le point de retrait, vous pouvez poursuivre normalement la procédure de retrait.

Une fois la commande récupérée, vous pourrez valider le retrait dans l'application.

Le bon de commande peut être présenté

Si le point de retrait vous demande le bon de commande, présentez-le directement à l'accueil.

Suivez les indications du point de retrait pour terminer la procédure de retrait.

Le problème empêche le retrait

Si malgré votre passage à l'accueil vous ne parvenez pas à récupérer la commande, contactez le support Allez HOP!.

Le support vous indiquera alors la marche à suivre.

Le problème n'empêche pas le retrait

Si le problème rencontré est mineur et que vous avez finalement pu récupérer la commande, vous pouvez poursuivre normalement votre course.

Une fois le retrait effectué, vous pouvez quitter le point de retrait et continuer votre trajet.

Y a-t-il un dédommagement ?

Non. Les problèmes liés au code-barres, à la référence ou au retrait font partie de la procédure de retrait et de ses éventuels aléas.

Ils ne donnent donc pas lieu à un dédommagement spécifique.

Besoin d'aide ?

Si le problème vous empêche de récupérer la commande, contactez directement le support Allez HOP!.

L'équipe vous indiquera la marche à suivre.
