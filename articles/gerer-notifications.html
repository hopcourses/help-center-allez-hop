Gérer les notifications

Activez et personnalisez vos notifications pour être informé des courses correspondant à vos trajets réguliers.

À quoi servent les notifications ?

Les notifications permettent de recevoir des informations ciblées sur les courses susceptibles de correspondre à vos trajets réguliers.

Les notifications sont un moyen pratique d'être alerté lorsqu'une course correspondant à vos critères devient disponible.

Où gérer les notifications ?

Vous pouvez gérer vos notifications depuis :

Page « Cotransporteur »

ou depuis :

Profil

Activer ses notifications

Les notifications ne sont pas activées automatiquement.

C'est à vous de les activer et de choisir celles que vous souhaitez recevoir.

Vous pouvez également désactiver vos notifications à tout moment.

Choisir les notifications souhaitées

Vous pouvez choisir le type de notifications que vous souhaitez recevoir.

Les notifications ciblées sont notamment liées aux trajets réguliers renseignés dans votre profil.

Comment fonctionnent les notifications ciblées ?

Les notifications ciblées fonctionnent à partir des codes postaux renseignés dans vos trajets réguliers.

1
Vos trajets réguliers

Vous renseignez vos codes postaux de départ et d'arrivée dans vos trajets réguliers.

2
Une course devient disponible

Une nouvelle course correspond à l'un des codes postaux renseignés.

3
Vous recevez une notification

Une notification ciblée peut vous informer de la disponibilité de cette course.

Départ ou arrivée

Une notification peut être envoyée lorsqu'une course correspond au :

  • départ d'une course ;
  • arrivée d'une course.

🏁 Correspondance au départ

Une course peut correspondre au code postal de départ renseigné dans l'un de vos trajets réguliers.

📍 Correspondance à l'arrivée

Une course peut également correspondre au code postal d'arrivée renseigné dans l'un de vos trajets réguliers.

Les moyens de transport sont-ils pris en compte ?

Non. Le moyen de transport renseigné dans votre profil n'est pas utilisé pour déterminer si vous recevez une notification ciblée.

Puis-je désactiver mes notifications ?

Oui. Vous pouvez activer ou désactiver vos notifications à tout moment.

Vous pouvez également choisir le type de notifications que vous souhaitez recevoir.

Et si je désactive les notifications ?

La désactivation des notifications ne vous empêche pas de rechercher des courses.

Vous pouvez toujours consulter les courses disponibles manuellement depuis la page « Cotransporteur ».

Notifications désactivées ? Vous pouvez toujours consulter les courses directement dans l'App web.

À retenir

🔔 Activation

Les notifications doivent être activées par vous.

⚙️ Gestion

Gérez-les depuis la page « Cotransporteur » ou depuis votre profil.

🎯 Notifications ciblées

Elles sont notamment liées à vos trajets réguliers et utilisent les codes postaux renseignés.

🏁 Départ ou arrivée

Une notification peut correspondre au départ ou à l'arrivée d'une course.

🔎 Recherche manuelle

Même sans notification, vous pouvez toujours consulter les courses manuellement depuis la page « Cotransporteur ».
