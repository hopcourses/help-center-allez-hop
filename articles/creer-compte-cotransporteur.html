Créer son compte cotransporteur

Les étapes pour créer votre compte et commencer votre inscription Allez HOP!.

Commencer son inscription

Vous souhaitez devenir cotransporteur Allez HOP! ? La création de votre compte commence directement depuis l'App web.

Adresse de l'App web :
www.allez-hop-app.hop-courses.com

Les étapes de l'inscription

1
Accédez à l'App web

Rendez-vous sur l'App web Allez HOP!.

2
Choisissez votre statut

Choisissez entre Particulier et Professionnel, puis cliquez sur « S'inscrire ».

3
Renseignez vos coordonnées

Renseignez vos coordonnées complètes.

4
Vérifiez votre adresse e-mail

Un code confidentiel vous est envoyé par e-mail. Saisissez ce code pour confirmer votre adresse e-mail.

5
Passez la vérification d'identité

Une vérification d'identité est effectuée. Si elle est positive, votre compte est créé.

Vous ne recevez pas le code par e-mail ?

Commencez par vérifier que l'adresse e-mail renseignée lors de l'inscription est correctement orthographiée.

Si le problème persiste malgré cette vérification, contactez le support Allez HOP!.

Une adresse e-mail ne peut pas être réutilisée

Une adresse e-mail déjà utilisée pour un compte ne peut pas être réutilisée pour créer un autre compte.

Particulier ou Professionnel ?

Avant de vous inscrire, choisissez le statut correspondant à votre activité :

  • Particulier
  • Professionnel

Vous pouvez par la suite vous inscrire également sous l'autre statut si vous le souhaitez.

À savoir : vous devez d'abord finaliser votre inscription avec l'un des deux statuts avant de vous inscrire sous le second.

Peut-on modifier son statut ?

Oui. Le statut choisi lors de l'inscription peut être modifié.

La vérification d'identité

La création du compte est soumise à une vérification d'identité.

Si cette vérification est positive, votre compte est créé.

Les documents et modalités de cette vérification sont présentés dans l'article consacré à la vérification d'identité et aux documents.

Les conditions pour devenir cotransporteur

Pour devenir cotransporteur, vous devez notamment :

  • être majeur ;
  • détenir les catégories de permis de conduire correspondant aux véhicules choisis.

Pour les cotransporteurs professionnels, il faut également détenir la licence de transport léger pour le transport de marchandises à l'aide d'un véhicule à moteur.

Depuis quel appareil peut-on s'inscrire ?

L'inscription est accessible depuis tous les types d'appareils : ordinateur, tablette ou téléphone.

Après la création du compte

Une fois votre compte créé, pensez à compléter votre profil afin de mieux paramétrer votre expérience de cotransporteur.

Vous pourrez notamment régler vos moyens de transport, votre rayon de recherche, vos trajets favoris et vos notifications.

Conseil : un profil correctement paramétré permet de recevoir des informations et des opportunités correspondant davantage à vos trajets.

À retenir

  • Rendez-vous sur l'App web Allez HOP!.
  • Choisissez Particulier ou Professionnel.
  • Renseignez vos coordonnées complètes.
  • Validez votre adresse e-mail avec le code confidentiel reçu par e-mail.
  • Passez la vérification d'identité.
  • Si la vérification est positive, votre compte est créé.
  • Vous devez être majeur et disposer des permis nécessaires.
  • Les professionnels doivent également détenir la licence de transport léger requise.

Besoin d'aide ?

Si vous rencontrez un problème lors de votre inscription, vérifiez d'abord les informations renseignées.

Si vous ne recevez pas votre code de vérification ou si le problème persiste, contactez le support Allez HOP!.
