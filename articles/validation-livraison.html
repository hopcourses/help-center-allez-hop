Comment valider une livraison ?

Comment valider correctement une livraison avec ou sans code confidentiel.

La validation de la livraison

Une fois la commande remise, la livraison doit être validée dans l'application.

Dans la situation habituelle, cette validation s'effectue à l'aide d'un code confidentiel remis par le destinataire.

À savoir : certaines situations ne permettent pas d'obtenir de code confidentiel. La livraison peut alors être validée sans code.

Valider avec le code confidentiel

Lorsque vous remettez directement la commande au destinataire, celui-ci vous communique son code confidentiel.

Saisissez ce code dans l'application afin de valider la livraison.

Le destinataire n'a pas de code

Dans certaines situations, il n'est pas possible d'obtenir de code confidentiel.

C'est notamment le cas pour :

  • une livraison de fleurs ;
  • une remise à un voisin ;
  • une situation dans laquelle le destinataire est absent et une autre solution de livraison est mise en place.

Dans ces situations, vous pouvez valider la livraison sans code.

Le bouton « Problème avec la livraison »

Si vous rencontrez une difficulté lors de la validation, vous pouvez utiliser le bouton « Problème avec la livraison ».

Cependant, si la livraison a bien été effectuée et qu'il est simplement impossible d'obtenir le code confidentiel, il n'est pas nécessaire de contacter le support avant de valider.

Utilisez directement la validation sans code.

Puis-je quitter les lieux ?

Oui.

Une fois la livraison effectuée et la validation réalisée, vous pouvez quitter les lieux.

Que se passe-t-il si je valide sans code ?

La livraison est bien enregistrée.

En revanche, lorsqu'aucun code confidentiel n'a été renseigné, une vérification est nécessaire avant de créditer la cagnotte du cotransporteur.

À savoir : le crédit de votre cagnotte peut donc être légèrement décalé lorsque la livraison est validée sans code.

Est-ce que je risque de ne pas être payé ?

Non.

L'absence de code ne signifie pas que la course n'est pas rémunérée.

Une vérification est simplement nécessaire lorsque la livraison est validée sans code avant le crédit de la cagnotte.

Cas des commerces partenaires

Il n'y a pas de procédure particulière pour les commerces partenaires.

La validation sans code est également possible.

Le crédit de la cagnotte peut simplement être légèrement décalé en raison de la vérification.

Besoin d'aide ?

Si vous rencontrez un véritable problème lors de la validation, utilisez le bouton « Problème avec la livraison » pour contacter le support Allez HOP!.
