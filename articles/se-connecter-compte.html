Se connecter à son compte

Connectez-vous simplement avec votre adresse e-mail et le code reçu par e-mail.

Comment se connecter ?

Si vous êtes déconnecté, rendez-vous sur la page d'accueil de l'App web.

Pour vous connecter, vous avez simplement besoin de votre adresse e-mail.

1
Renseignez votre adresse e-mail

Utilisez l'adresse e-mail associée à votre compte Allez HOP!.

2
Recevez votre code

Un code de connexion vous est envoyé par e-mail.

3
Saisissez le code

Utilisez le code reçu pour accéder à votre compte.

Bon à savoir : Allez HOP! n'utilise pas de mot de passe pour la connexion.

Il n'y a pas de mot de passe

Vous n'avez pas besoin de mémoriser ou de réinitialiser un mot de passe.

La connexion s'effectue avec votre adresse e-mail et le code reçu par e-mail.

La session reste ouverte

Une fois connecté, votre session reste ouverte tant que vous ne vous déconnectez pas.

Vous n'avez donc pas besoin de vous reconnecter à chaque utilisation de l'App web.

Vous ne recevez pas le code ?

Commencez par vérifier que l' adresse e-mail renseignée est correctement orthographiée.

Si le problème persiste, contactez le support par e-mail.

📧 Vérifiez d'abord votre adresse

Une simple erreur dans l'adresse e-mail peut empêcher la réception du code de connexion.

Se connecter depuis plusieurs appareils

Vous pouvez vous connecter depuis tout type d'appareil :

  • ordinateur ;
  • tablette ;
  • téléphone.

Votre compte peut également être utilisé sur plusieurs appareils.

Se déconnecter

Vous pouvez vous déconnecter manuellement depuis votre compte.

Une fois déconnecté, il faudra à nouveau renseigner votre adresse e-mail et utiliser le code reçu par e-mail pour vous connecter.

Compte Particulier ou Professionnel

La procédure de connexion est la même pour les profils Particulier et Professionnel.

Si vous disposez des deux profils, vous pouvez passer de l'un à l'autre directement depuis le dashboard.

Une seule connexion suffit : la bascule entre vos profils s'effectue directement depuis le dashboard.

Mon compte est restreint

Lorsqu'un compte est temporairement restreint, l'affichage des courses est restreint.

La restriction concerne donc l'accès aux courses disponibles et ne modifie pas la méthode habituelle de connexion au compte.

À retenir

📧 Adresse e-mail

La connexion utilise l'adresse e-mail associée à votre compte.

🔐 Code de connexion

Un code vous est envoyé par e-mail. Il n'y a pas de mot de passe.

🔄 Session

La session reste ouverte tant que vous ne vous déconnectez pas.

💻 Plusieurs appareils

Vous pouvez utiliser votre compte depuis tout appareil et sur plusieurs appareils.

🔀 Plusieurs profils

Si vous disposez d'un profil Particulier et d'un profil Professionnel, vous pouvez basculer entre les deux depuis le dashboard.

⚠️ Compte restreint

L'affichage des courses est alors restreint.

Besoin d'aide ?

Si vous ne recevez pas votre code après avoir vérifié l'orthographe de votre adresse e-mail, contactez le support par e-mail.
