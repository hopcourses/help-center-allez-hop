Particulier ou Professionnel ?

Comprendre les deux types de profils et passer facilement de l'un à l'autre.

Choisir son profil

Lors de votre inscription sur Allez HOP!, vous choisissez le type de profil que vous souhaitez utiliser :

👤 Particulier

  • Profil destiné à une activité de cotransporteur en tant que particulier.
  • Fonctionnement des courses identique au profil Professionnel.

🏢 Professionnel

  • Profil destiné à une activité professionnelle.
  • Informations et documents professionnels supplémentaires.

Quelle est la différence ?

Pour l'utilisation d'Allez HOP!, les règles de fonctionnement des courses sont les mêmes, que vous utilisiez un profil Particulier ou Professionnel.

La distinction concerne principalement :

  • la destination finale des gains ;
  • les informations figurant sur la fiche DAC7.

À retenir : le choix du profil ne change pas les règles applicables aux courses.

Peut-on avoir les deux profils ?

Oui. Un même utilisateur peut disposer d'un profil Particulier et d'un profil Professionnel.

Les deux profils peuvent utiliser la même adresse e-mail.

Il est possible d'avoir au maximum :

  • un profil Particulier ;
  • un profil Professionnel.

Passer d'un profil à l'autre

Si vous disposez des deux profils, vous pouvez passer de l'un à l'autre directement depuis le dashboard.

Dashboard → Particulier / Pro

Sélectionnez simplement le profil avec lequel vous souhaitez utiliser l'application.

Peut-on changer de statut ?

Oui.

Si vous disposez actuellement d'un seul profil, vous pouvez demander la création de l'autre profil sans avoir à créer un nouveau compte.

🔄 Particulier → Professionnel

Contactez le support afin que votre profil Professionnel puisse être correctement configuré.

🔄 Professionnel → Particulier

Contactez également le support pour effectuer cette modification.

Documents nécessaires pour un profil Professionnel

Le profil Professionnel nécessite des informations et documents supplémentaires.

Vous devrez notamment fournir :

  • un extrait K-bis ;
  • votre numéro SIRET.

RIB professionnel

Lorsqu'il s'agit d'une personne morale, le RIB professionnel doit être au nom de l'entreprise.

🏦 Le compte bancaire utilisé pour les opérations professionnelles doit donc correspondre à l'entreprise concernée.

Licence de transport

La licence de transport léger est nécessaire uniquement pour le transport de marchandises avec un véhicule à moteur.

Elle n'est donc pas nécessaire simplement parce que vous utilisez un profil Professionnel.

Les courses sont-elles différentes ?

Non. Les règles de fonctionnement des courses sont les mêmes pour les profils Particulier et Professionnel.

Les paiements sont-ils différents ?

Non. Le fonctionnement des paiements et de la cagnotte n'est pas différent selon le type de profil.

La distinction concerne notamment la destination finale des gains et leur traitement dans les informations déclaratives, notamment la fiche DAC7.

Peut-on utiliser les deux profils en même temps ?

Non.

Vous pouvez disposer des deux profils, mais vous utilisez l'un ou l'autre en fonction du profil sélectionné dans l'application.

Je me suis trompé de statut

Si vous avez sélectionné le mauvais statut lors de votre inscription, pas d'inquiétude.

Contactez le support afin qu'il vous indique la marche à suivre.

À retenir

👤 Particulier ou 🏢 Professionnel

Vous choisissez l'un des deux profils lors de votre inscription.

🔄 Les deux profils

Vous pouvez disposer d'un profil Particulier et d'un profil Professionnel avec la même adresse e-mail.

🔀 Bascule

Passez d'un profil à l'autre depuis Dashboard → Particulier / Pro.

📄 Professionnel

Le profil Professionnel nécessite notamment un extrait K-bis et un SIRET.

🚚 Licence

La licence de transport léger est nécessaire uniquement pour le transport de marchandises avec un véhicule à moteur.

📋 DAC7

La distinction entre les profils concerne notamment la destination finale des gains et les informations de la fiche DAC7.

Besoin d'aide ?

Si vous avez choisi le mauvais statut ou si vous avez besoin d'aide pour créer ou gérer votre profil Professionnel, contactez le support Allez HOP!.
